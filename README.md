## Live Demo – Judge Access

**Live Application:** https://careloop-ai-lck8.onrender.com/login

You can explore CARELOOP-AI using the following demo accounts. Each account represents a different role in the care circle.

### How to Join

1. Open the [CARELOOP-AI Live Demo](https://careloop-ai-lck8.onrender.com/login).
2. On the login page, select **Register with an invitation**.
3. Enter the invitation code for the role you want to explore.
4. Click **Join care circle**.
5. Explore the dashboard and available features.
